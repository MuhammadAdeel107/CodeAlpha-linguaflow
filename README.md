# LinguaFlow

LinguaFlow is a professional language translation web application built with Python, Flask, JavaScript, and Google Cloud Translation.

## Features

- Multi-language translation
- Automatic language detection
- Source and target language selection
- Language swapping
- Copy translation
- Character counter
- Dark mode
- Responsive UI
- REST API
- Input validation
- Automated tests
- Vercel deployment ready

## Tech Stack

- Python
- Flask
- Google Cloud Translation
- JavaScript
- HTML5
- CSS3
- uv
- pytest
- Vercel
